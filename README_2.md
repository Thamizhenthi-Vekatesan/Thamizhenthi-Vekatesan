# Thamizh — UI/UX Portfolio

Personal portfolio of Thamizhenthi Venkatesan, UI/UX Designer and Frontend Developer based in Dubai. It presents product projects, design explorations, skills and a contact form.

**Live site:** https://thamizhuiux.vercel.app/ <!-- confirm this repo is the source of the live site; see notes -->

<!-- ![Portfolio home page](docs/screenshot-home.png) -->

## Features

- Hero with animated headline and résumé / contact actions
- Project gallery with case-study cards
- Design explorations wall
- Skills section
- Contact form with toast feedback
- Responsive layout and theme support

## Built with

React 18 · TypeScript · Vite · Tailwind CSS · shadcn/ui (Radix UI) · React Router · Lucide icons

## Run locally

Requires Node.js 18 or later.

```bash
git clone https://github.com/Thamizhenthi-Vekatesan/My-Portfolio.git
cd My-Portfolio
npm install
npm run dev      # start the dev server
npm run build    # production build in dist/
```

## Project structure

```
src/
├── components/     # Navbar, Footer, ProjectCard, DesignCard, SkillCard, ContactForm
│   └── ui/         # shadcn/ui primitives
├── contexts/       # App state
├── pages/          # Index, NotFound
└── assets/         # Images
```
